# Retain verified conference labels from reading searches

- **Feedback:** Check the shared catalog before looking up conference labels. When a search turns up a paper with a newly verified Best Paper, Outstanding Paper, Spotlight, or Oral label, save it so it can be found again.
- **Affected workflow:** Paper discovery and prioritization. The [Copilot instructions](../.github/copilot-instructions.md) direct searches to update the [verified-paper catalog](../discovery/resources/bestpaper_list.md#verified-papers), and [search-related](../.github/skills/search-related/SKILL.md#search-for-related-papers) checks it before looking up new evidence.
- **Expected improvement:** Future searches can reuse verified entries without duplicating them or confusing presentation formats with awards.
