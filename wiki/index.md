# Research wiki

- [OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments](papers/2024/arxiv-2404.07972.md) — Tests computer-use agents on real desktop tasks with executable, task-specific evaluation.
- [τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains](papers/2024/arxiv-2406.12045.md) — Tests whether agents can reliably complete the same policy-constrained task across multiple conversations with simulated users.
- [SWE-bench: Can Language Models Resolve Real-World GitHub Issues?](papers/2024/arxiv-2310.06770.md) — Tests whether model-generated patches resolve real issues in Python repositories without breaking behavior covered by regression tests.
- [Terminal-Bench: Benchmarking Agents on Hard, Realistic Tasks in Command Line Interfaces](papers/2026/arxiv-2601.11868.md) — Tests whether agents can complete realistic command-line tasks by checking the final container state.
